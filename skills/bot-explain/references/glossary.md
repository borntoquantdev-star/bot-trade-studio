# คลังคำศัพท์ — อธิบายเป็นภาษาคน

ใช้เป็นจุดตั้งต้น **ต้องขยายด้วยตัวเลขจริงจากสเปคของผู้ใช้เสมอ**

## เกี่ยวกับผลตอบแทนและความเสี่ยง

| คำ | ภาษาคน |
|---|---|
| **Drawdown** | เงินลดลงเท่าไหร่จากยอดสูงสุดที่เคยไปถึง ไม่ใช่จากเงินต้น |
| **Max drawdown** | ช่วงที่เจ็บที่สุดที่เคยเกิด — ตัวเลขที่สำคัญกว่ากำไร |
| **CAGR** | ถ้าผลตอบแทนทั้งหมดนี้เฉลี่ยเท่ากันทุกปี จะได้ปีละกี่ % |
| **Sharpe ratio** | ได้กำไรคุ้มกับความเหวี่ยงที่ทนไหม ยิ่งสูงยิ่งดี เกิน 1 ถือว่าใช้ได้ เกิน 3 น่าสงสัยว่า backtest โกง |
| **Profit factor** | เงินที่ได้ ÷ เงินที่เสีย ได้ 1.5 แปลว่าเสีย 100 ได้ 150 |
| **R** | หน่วยวัดเป็น "กี่เท่าของเงินที่เสี่ยงต่อไม้" ถ้าเสี่ยงไม้ละ 500 บาท กำไร 3R = ได้ 1,500 บาท |
| **Expectancy** | กำไรเฉลี่ยต่อไม้ รวมไม้ที่แพ้แล้ว ถ้าติดลบ แปลว่ายิ่งเทรดยิ่งจน |
| **Win rate** | ชนะกี่ % ของไม้ทั้งหมด **ตัวเลขนี้ลำพังไม่มีความหมาย** ต้องดูคู่กับขนาดกำไร/ขาดทุนเฉลี่ย |

## เกี่ยวกับการเข้า-ออก

| คำ | ภาษาคน |
|---|---|
| **Stop loss** | ราคาที่ยอมรับว่าคิดผิด แล้วออกเพื่อหยุดเลือด — ตั้งไว้ตั้งแต่ก่อนเข้า |
| **Take profit** | ราคาที่ตั้งใจจะขายทำกำไร |
| **Trailing stop** | จุดตัดขาดทุนที่ขยับตามราคาขึ้นไปเรื่อยๆ ล็อกกำไรไปด้วย แต่ไม่ขยับลง |
| **Time stop** | ถือมานานแล้วยังไม่ไปไหน ให้ขายทิ้งไปหาโอกาสอื่น |
| **Slippage** | ราคาที่ได้จริง ต่างจากราคาที่ตั้งใจ — เกิดเพราะราคาวิ่งระหว่างที่คำสั่งเดินทาง |
| **Spread** | ส่วนต่างระหว่างราคาที่คนอยากซื้อกับคนอยากขาย คุณจ่ายส่วนนี้ทุกครั้งที่เทรด |
| **Limit order** | สั่งซื้อที่ราคาไม่เกินเท่านี้ — ได้ราคาดี แต่อาจไม่ได้ของ |
| **Market order** | สั่งซื้อที่ราคาไหนก็ได้ตอนนี้ — ได้ของแน่ แต่อาจได้ราคาแย่ |
| **Gap** | ราคากระโดดข้ามช่วงไป ทำให้ stop ทำงานที่ราคาแย่กว่าที่ตั้งไว้ |

## เกี่ยวกับตัวชี้วัด

| คำ | ภาษาคน |
|---|---|
| **MA / EMA** | ราคาเฉลี่ยย้อนหลัง N แท่ง ใช้ดูทิศทางโดยรวม ตัดเสียงรบกวนออก |
| **ATR** | ปกติแล้วราคาตัวนี้แกว่งวันละเท่าไหร่ ใช้ตั้ง stop ให้พอดีกับนิสัยของมัน |
| **RSI** | 0–100 บอกว่าเพิ่งขึ้นแรงหรือลงแรงมาเมื่อเร็วๆ นี้ ไม่ได้บอกว่าจะกลับตัว |
| **Bollinger Bands** | กรอบที่ราคามักอยู่ข้างใน คำนวณจากความเหวี่ยง หลุดกรอบ = ผิดปกติ แต่ไม่ได้แปลว่าจะกลับ |
| **Donchian channel** | จุดสูงสุด/ต่ำสุดใน N แท่งที่ผ่านมา ใช้จับการทะลุ |
| **Volume** | ปริมาณการซื้อขาย ใช้ยืนยันว่าการเคลื่อนไหวมีคนจริงอยู่เบื้องหลัง |

## เกี่ยวกับการทดสอบ

| คำ | ภาษาคน |
|---|---|
| **Backtest** | จำลองว่าถ้าใช้กฎนี้ในอดีตจะเกิดอะไร — **ไม่ใช่คำทำนายอนาคต** |
| **Overfitting** | ปรับกฎจนพอดีกับอดีตเป๊ะ แล้วใช้กับอนาคตไม่ได้ เหมือนท่องข้อสอบเก่าแทนที่จะเข้าใจเนื้อหา |
| **In-sample / Out-of-sample** | ข้อมูลที่ใช้ออกแบบได้ / ข้อมูลที่กันไว้ห้ามแตะ เพื่อทดสอบว่าจริงไหม |
| **Walk-forward** | ทดสอบแบบเลื่อนหน้าต่างไปเรื่อยๆ เหมือนใช้งานจริงมากกว่า backtest ธรรมดา |
| **Paper trading** | เทรดด้วยเงินปลอมบนราคาจริง เพื่อหาบั๊กก่อนเสียเงิน |
| **Survivorship bias** | ทดสอบเฉพาะกับของที่รอดมาถึงวันนี้ ทำให้ผลดูดีเกินจริง |
| **Lookahead bias** | เผลอใช้ข้อมูลที่ตอนนั้นยังไม่มี = โกงตัวเอง backtest จะสวยมากและใช้จริงไม่ได้เลย |

## เกี่ยวกับการต่อระบบ

| คำ | ภาษาคน |
|---|---|
| **API key** | กุญแจให้โปรแกรมเข้าบัญชีแทนคุณ — **ห้ามเปิดสิทธิ์ถอนเงินเด็ดขาด** |
| **Idempotency key** | รหัสกันสั่งซ้ำ ถ้าเน็ตหลุดแล้วส่งใหม่ ตลาดจะรู้ว่าเป็นคำสั่งเดิม ไม่เปิดซ้อน |
| **Reconcile** | ถามตลาดว่า "ตอนนี้ฉันถืออะไรอยู่จริงๆ" แล้วเทียบกับที่บอทคิด ถ้าไม่ตรงต้องหยุด |
| **Rate limit** | โควต้าว่ายิงคำสั่งได้กี่ครั้งต่อนาที เกินแล้วโดนตัด |
| **Testnet** | ตลาดจำลองของเอ็กซ์เชนจ์ ใช้ทดสอบว่าโค้ดส่งคำสั่งได้ |
| **Kill switch** | สวิตช์หยุดอัตโนมัติเมื่อขาดทุนถึงเพดาน และ **ไม่เปิดเองกลับมา** |

## เกี่ยวกับความเสี่ยงขั้นสูง

| คำ | ภาษาคน |
|---|---|
| **Leverage** | ยืมเงินมาเทรด กำไรคูณ ขาดทุนก็คูณ |
| **Liquidation** | ขาดทุนจนเงินประกันไม่พอ ตลาดบังคับปิดให้ **เงินส่วนนั้นหายทันที** |
| **Funding rate** | ค่าธรรมเนียมที่ฝั่งซื้อกับฝั่งขายจ่ายกันใน perpetual futures ทุกไม่กี่ชั่วโมง |
| **Market impact** | ไม้ใหญ่เกินสภาพคล่อง ทำให้ราคาขยับเพราะตัวเอง ได้ราคาแย่ลง |
| **Tail risk** | เหตุการณ์ที่นานๆ เกิดที แต่เกิดทีเสียหายมหาศาล |
| **Correlation** | สินทรัพย์ที่ขึ้นลงพร้อมกัน ถือหลายตัวที่ correlate สูง = ไม่ได้กระจายความเสี่ยงจริง |
