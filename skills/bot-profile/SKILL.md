# ขั้นที่ 1 — รู้จักผู้ใช้ก่อนออกแบบบอท

เป้าหมายไม่ใช่เก็บข้อมูล แต่คือ**หาเพดานความเจ็บที่เขารับได้จริง** เพราะบอทส่วนใหญ่ไม่ได้ตายเพราะกลยุทธ์ผิด แต่ตายเพราะเจ้าของปิดมันทิ้งตอนขาดทุน แล้วมันฟื้นหลังจากนั้น

## วิธีถาม

ถาม **ทีละกลุ่ม** ใช้ AskUserQuestion ให้เขากดเลือก อย่าถามรวดเดียว 8 ข้อ
หลังแต่ละกลุ่ม สะท้อนกลับสั้นๆ ว่าคำตอบนั้นแปลว่าอะไรต่อบอท

### กลุ่ม 1 — เงิน

1. **ทุนตั้งต้นเท่าไหร่** และเป็นสกุลอะไร
2. **เงินก้อนนี้หายไปทั้งหมด ชีวิตเปลี่ยนไหม**
   - ถ้าตอบว่าเปลี่ยน → หยุดตรงนี้ บอกตรงๆ ว่า **อย่าเพิ่งทำบอทด้วยเงินก้อนนี้** เสนอให้เริ่มด้วยเงินที่เสียได้ หรือทำแบบ paper อย่างเดียวไปก่อน
3. ถ้าทุนน้อยกว่าประมาณ 30,000 บาท / 1,000 USD → เตือนว่าค่าธรรมเนียมกับค่า spread จะกินสัดส่วนสูงมาก กลยุทธ์ที่เทรดถี่จะไม่เหลือกำไร

### กลุ่ม 2 — ความเจ็บ (สำคัญที่สุด)

4. **เงินลดจากจุดสูงสุดกี่เปอร์เซ็นต์ คุณจะเริ่มนอนไม่หลับ** (max drawdown)
   ให้ตัวเลือกเป็นจำนวนเงินจริงด้วย ไม่ใช่แค่ % เช่น "15% = เงิน 50,000 เหลือ 42,500"
5. **ขาดทุนติดกันกี่เดือน ถึงจะเลิก**
   อธิบายว่ากลยุทธ์ตามเทรนด์ที่ดีมาก ก็มีช่วงขาดทุนติดกัน 6–9 เดือนเป็นเรื่องปกติ

> ถ้าเขาตอบว่ารับ drawdown ได้แค่ 5% และขาดทุนติดกันได้ 1 เดือน → บอกตรงๆ ว่าแทบไม่มีกลยุทธ์เทรดไหนผ่านเกณฑ์นี้ และแนะนำแนว DCA หรือ portfolio rebalance แทน

### กลุ่ม 3 — เวลาและความสามารถ

6. **วันหนึ่งดูบอทได้จริงกี่นาที** และ **ตื่นมาดูตอนกลางคืนได้ไหม**
   - 0–15 นาที/วัน → ต้องเป็น D1 หรือ H4 ขึ้นไป และต้องมี kill switch อัตโนมัติ
   - ดูกลางคืนไม่ได้ แต่อยากเทรดคริปโต → ย้ำว่าตลาดเปิด 24 ชม. ต้องมีสวิตช์หยุดอัตโนมัติแน่นอน
7. **เคยเทรดเองมาก่อนไหม** (ไม่เคย / เคยบ้าง / เทรดประจำ)
   - ไม่เคยเทรดเองเลย → เตือนว่าบอทจะขยายผลของกลยุทธ์ที่ยังไม่เคยพิสูจน์ ให้ตั้งทุนเริ่มต้นต่ำมาก

### กลุ่ม 4 — สนาม

8. **ตลาดไหน** — คริปโต / หุ้นไทย / TFEX / ฟอเร็กซ์ / หุ้นสหรัฐ
   บอกข้อแลกเปลี่ยนสั้นๆ ของแต่ละอัน:
   - คริปโต: เปิด 24/7 ข้อมูลฟรี API ง่ายที่สุด แต่เหวี่ยงแรงและมีความเสี่ยงจากตัวเอ็กซ์เชนจ์เอง
   - หุ้นไทย: ข้อมูลหายาก ค่าธรรมเนียมสูง API โบรกจำกัด ชอร์ตยาก
   - TFEX: มี leverage ในตัว API พอมี เหมาะกับระบบที่ทดสอบแล้ว
   - ฟอเร็กซ์ (MT5): API ครบ สภาพคล่องสูง แต่โบรกคุณภาพต่างกันมาก
   - หุ้นสหรัฐ: ข้อมูลดีที่สุด (Alpaca/IBKR) แต่มีเรื่องภาษีและเวลาตลาดกลางคืนไทย
9. **มีอะไรที่ยอมไม่ได้เด็ดขาดไหม** (เช่น ห้าม leverage, ห้ามชอร์ต, ห้ามเทรดเหรียญ meme)

## ผลลัพธ์ที่ต้องส่งมอบ

1. เขียน `bot/profile.yaml` ตามรูปแบบใน `../bot-home/references/spec-schema.md`
2. เขียน/อัปเดต `bot/STATUS.md` ว่าขั้น 1 เสร็จแล้ว
3. สรุปให้ผู้ใช้อ่าน **ไม่เกิน 10 บรรทัด** ว่า
   - โปรไฟล์ของเขาคืออะไร
   - **กลยุทธ์กลุ่มไหนที่เหมาะ** (ชื่อกลุ่ม 2–3 ชื่อ พร้อมเหตุผลหนึ่งบรรทัด)
   - **กลยุทธ์กลุ่มไหนที่ไม่ควรแตะ** และเพราะอะไร
4. ชวนไปขั้นต่อไป: `/bot:strategy`

## ตารางจับคู่โปรไฟล์กับกลยุทธ์

ใช้เป็นแนว ไม่ใช่กฎตายตัว รายละเอียดเต็มอยู่ใน `../bot-strategy/references/catalog.md`

| โปรไฟล์ | เหมาะ | ไม่เหมาะ |
|---|---|---|
| ทุนน้อย เวลาน้อย มือใหม่ | DCA, Portfolio rebalance, Momentum rotation | Grid, Scalping, Pairs |
| รับ DD ได้ 20%+ รอได้เป็นปี | Trend following, Breakout | Mean reversion ที่ไม่มี stop |
| อยากเห็นกำไรบ่อย ทนขาดทุนก้อนใหญ่ครั้งเดียวได้ | Mean reversion (ต้องมี stop เข้ม) | Trend following |
| ดูจอได้ทั้งวัน มีประสบการณ์ | Breakout, Event/News | — |
| ต้องการผลตอบแทนนิ่ง ไม่หวือหวา | Carry/Funding, Portfolio rebalance | Grid, Momentum เดี่ยว |
| รับ DD ได้ต่ำกว่า 8% | DCA, Portfolio rebalance เท่านั้น | แทบทุกกลยุทธ์เทรด |

## สิ่งที่ห้ามทำในขั้นนี้

- ห้ามเดาคำตอบแทนผู้ใช้แล้วเขียนลง YAML
- ห้ามบอกว่ากลยุทธ์ไหน "ดีที่สุด" — บอกว่า "เหมาะกับโปรไฟล์คุณที่สุด" และแลกอะไรไป
- ห้ามพูดถึงผลตอบแทนคาดหวังเป็นตัวเลขในขั้นนี้ รอจนถึง backtest
